## 阶段计时

原先浏览器导出只有排队与改写两个服务端计时，无法用于比较上下文、检索、上游等待和正文确认的观测值。本轮增加 `server_timings_ms`，与服务端公开协议使用相同的 18 个数值白名单；原有 `server_queue_ms`、`rewrite_ms` 继续保留。

仅接受 0–3600000ms 的有限数值，不接受布尔值、字符串、任意供应商诊断或未知字段。没有测量的阶段保持缺失。导出仍只保留最近 100 轮的内存记录，不新增上传、持久化或模型调用，不包含正文、凭证、原始请求 UUID 或私人型号标识。

`latency_report.py` 为每个阶段报告测量数、缺失数、P50、P95 和超过 5 秒的观察数。阶段统计仅采用新生成样本；原 UUID 的缓存恢复另列，回放的服务端计时不视为新生成测量。旧浏览器导出仍可读取，但未提供的阶段无法追补。

超过 5 秒的首段样本分别列出首段前的阶段观察与后续完整生成、改写、校验、保存的观察。它们不等于原因归属：计时可能重叠、包含其他阶段，起点也可能不同，不能相加。完整生成耗时较长不代表已提前显示的首段同样等待了这么久；上游首个 content 也可能只是 JSON 元数据。缺少超预算观察时，原因标为未验证，不能推断各阶段都很快。

## 真实使用样本

用户已选择在正常聊天时收集匿名计时，不新增付费测试调用。五家渠道按确切型号分别验收；DeepSeek Flash 可作为对照。保持原有模型、人设、记忆、媒介和历史，覆盖普通闲聊、长历史、复杂剧情与异常，并单独记录设备、浏览器、网络条件及候选版本。

浏览器中的导出方法保持不变：

```javascript
window.__projectSnowPerformance.getSamples()
```

在 `App` 目录下，对保存的 JSON 数组或 JSONL 运行：

```text
python scripts/latency_report.py timing-export.json
```

每个具体型号至少 30 个新生成样本。避免将重叠的导出批次重复合并；失败、部分回复和缺失首段测量都保留在原分母中。达标要求仍为首段 P95 ≤5000ms、成功且首段按时比例 ≥95%；自然等待单列，正文就绪到浏览器绘制的额外开销 ≤100ms。

报表的 `all` 结论只描述所提供样本的汇总，不能证明覆盖了五家渠道或所有型号。未知型号的分组不能取得已验证达标结论。任何缺少真实样本的型号，以及实体移动设备、软键盘和人工自然度验收，继续标记未验证；合成流和无头浏览器测试不能替代这些结果。

## 提前交付的句段保护

审查发现，结构完整的 JSON 对象仍可能只包含“因为”“我其实”这样的残句。公开聊天的原有人设、事实、安全守卫与四类确定性修复比对继续先执行，再用独立的提前交付判定检查明确句末、引用/括号闭合，以及有限的残句结尾和中英文等待占位。

未通过这项判定时仅等待全文，不补字或标点、不改变全文合法性、不增加模型调用。合法未标点首段仍可正常完成；如果第一段已确认，后续合法未标点段也只延后交付，保留先前确认内容，最终 `done` 正常完成。它不能证明普遍的语义相关性或完整语法；质量与真实有效首段仍须人工样本审查。

## 长历史与历史对白

长历史测试改为在临时 IndexedDB 保存 350 条合成记录，再使用真实分页加载至 200 条可见消息。原实现进入面对面时仍多次构建隐藏的通讯器历史；现在在动效开关开启且通讯器隐藏时跳过，返回可见界面后再根据真实历史窗口更新，保留原消息、游标和滚动逻辑。

面对面的逐字呈现只用于当前请求或当前呈现队列。重载和历史对白直接显示完整内容；新回复、快进、后台结束逐字与业务完成解锁仍沿用原有归属检查。两个开关关闭时保留旧行为。

通讯器读取历史时标记入场已处理，缺少原始时间的记录也不播放入场动画。原有 ID 缓存保持 1000 项上限；另用非持久化 `WeakSet` 记录仍存活的消息对象，避免 ID 淘汰后缓存历史再次播放，同时不额外强引用旧消息。固定时钟的浏览器回归在基线明确重放历史、修复后没有重放，新发送与确认回复仍各正常入场一次。

返回通讯器时，已处理消息跳过逐行 DOM 扫描；相同标记和相同直接子节点可复用原渲染结果，结构变化或正文追加仍按原规则更新。实际 DOM 回归覆盖焦点、输入值与选区、直接 Text 节点的外部插入、删除、替换、重排及已确认正文的追加。

剩余热点通过匿名函数采样定位：日期分组反复构造 `Intl.DateTimeFormat` 约 25ms，首次显示 200 行的布局读取约 24ms。现在固定香港日期格式化器复用，设备本地时钟格式化器在每轮渲染时重新解析默认语言/时区并仅轮内复用，保留原有跨日、24 小时制和估算标记；洛杉矶/英文浏览器的香港午夜回归通过。采样代码只用于临时合成诊断，未进入产品；正式性能结果均使用未插入采样代码的浏览器。

现有开关开启时，已核实官方型号的完整回复也会采用上游 SSE，即使该回合不能提前交付；开启验收须覆盖各渠道的完整 SSE 契约。遇到流传输或格式故障不会自动重试非流式调用，以免重复计费。个人订阅及未知型号仍保留原有处理。
