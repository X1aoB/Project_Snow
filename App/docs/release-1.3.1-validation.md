# 1.3.1 关系事实守卫补丁

## 依据与范围

1.3.0 已上线，生产提交为 `0fda94121c3999fb537f191437fc4e271a542334`。后续独立合成审查发现正式关系守卫对强调语气、双人称呼、夫妇同义词及名单尾语气词存在漏检。这不是原反馈私有对话的复现，也不证明线上模型实际生成了这些文本。

补丁保持人物表达与事实边界分离，不改变后台主动消息、聊天存储、模型配置、公共 API 或数据库结构。既有 1.3.0 发布不覆盖。

## 回归设计

使用合成回答调用实际 `_answer_guardrail_violations`，并覆盖全部非正式关系角色、名单追加、否定/愿望/条件与第三人称对照。流式测试使用实际 `communication_context.channel`，同时验证合规内容可发布和错误正式关系断言不发布，避免通信类型错误导致阴性测试空过。

新工作树使用 `scripts/prepare_ci_runtime.py` 生成无语料 CI 夹具，不复制或修改线上聊天及私有运行数据。

## 最终本地验证

最终代码的事实/人物表达、应用层、延迟、审核状态、22 角色及前端版本/发布清单/部署契约合计 **337 passed、1061 subtests passed、1 skipped、18 runtime_data deselected**。运行使用 Python UTF-8 模式及无语料 CI 夹具；所有模型调用均被合成替身替代。初次扩展运行在缺少夹具的工作树失败，生成仓库提供的夹具后重跑通过，未读取私有运行语料。Astra 独立审查为强调语气新增子场景，先确认 74 个子场景在首版补丁失败，再确认修正后通过。

本地验证不是 Linux 全量 CI 或人工人物表现评测。精确提交 CI 仍需通过。

## 发布状态

实现及本地定向验证完成，尚未发布。最终测试、精确提交 CI、签名发布证明、公告预检、候选验收与回退锚点均需在发布前核对。晋级需要该候选的具体人工验收批准，不复用 1.3.0 收据。
