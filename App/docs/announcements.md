# 公告与角色生日

公网页面的文字聊天和面对面界面都在右上角保留「!」入口。进入网站并确认体验说明后，有未读的新公告或当天生日时自动打开公告。看过并关闭的内容保存在当前浏览器，下次进入不会重复提示；新公告以及下一年的生日会再次提醒。生日统一使用北京时间（UTC+8），开着页面跨过零点或重新返回页面也会更新。

## 发布公告

编辑 `App/public_frontend/announcements.json` 的 `updates` 数组，正常提交、通过 CI 并部署即可发布。公告接口不依赖模型凭证；加载失败时可在公告窗口重试，聊天仍可继续。

- 每条公告使用唯一且稳定的 `id`。
- `published_at` 使用带时区的 ISO 时间，例如 `2026-09-05T13:00:00+08:00`。到达发布时间后才显示，列表按发布时间倒序排列。
- `title`、`summary` 和 `items` 都是纯文本，不支持 HTML。
- 修订已经发布的内容并需要重新提示时，更新 `updated_at`；新公告使用新的 `id`。最新公告在更新页显示，过往公告仍可回看。
- 公告 JSON 禁止缓存；页面在进入、返回及保持打开期间定期检查，并在读到新内容后提示。已打开其他对话框或正在生成回复时会延后弹出。

已读记录只在当前浏览器内生效，同源标签页会同步。浏览器禁止保存公告记录时，当次访问仍能记住已读状态；之后重新进入可能再次提示。

## 生日资料

`birthdays` 包含当前角色注册表中的全部 22 位角色。`character_id` 对应角色注册表，`month` 和 `day` 为真实月日；`source_url` 指向已有许可审查记录中固定版本的 Wiki 资料。数据核对范围包括角色资料页和装甲资料页的「生日」字段，没有从生日邮件的发送日期推测生日。

补充角色时，同步补充生日资料并核对来源。日期未知时应先确认资料，不能编造日期。生日列表显示当天、接下来三位和完整日历；同日多位角色分别展示，每位每年独立记忆已读状态。Wiki 资料入口保留在角色行中。

## 验证

在 `App` 下执行：

```powershell
.venv/Scripts/python.exe -m pytest tests/test_public_announcements.py -q
$env:RUN_PUBLIC_E2E = '1'
.venv/Scripts/python.exe -m pytest tests/test_public_frontend_e2e.py -k announcement -q
```

便携测试验证生日全量覆盖、来源许可记录、有效日期和公告结构；本地存在原始资料时还逐项对照生日原文。浏览器测试覆盖自动提示、已读记忆、新公告、生日跨日与跨年、失败重试、对话框协调、键盘操作及手机布局。
