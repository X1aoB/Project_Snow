# 路由后 A/B 可行性审计

`scripts/voice_composition_viability_ops.py` 只重新计算路由后的基础词汇片段数量和时长，
不会生成拼接音频，也不会把“时长合格”写成完整声学 QC 通过。

审计固定引用语料路由凭据、review package、span queue，以及既有 10–20 秒、
1–4 个父片段和 A/B 内容互斥规则。每个槽位使用队列固定的 150 ms 连接静音重新计算。

当前结果：

- 薇蒂雅 A：7.65 秒，缺 2.35 秒；B：12.64 秒，时长合格但仍待完整 QC。
- 辰星 A：10.00 秒，时长合格但仍待完整 QC；B：6.52 秒，缺 3.48 秒。
- 两个角色都只有一个槽位达到时长门槛，因此完整 A/B 候选角色数为 0。
