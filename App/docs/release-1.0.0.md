# 小吉终端 1.0.0 发布说明

1.0.0 改善日常聊天的呈现与角色切换体验，并让每位使用者通过个人连接器使用自己的 Codex 订阅。生产上线状态以绑定具体提交、镜像摘要和前端产物的发布回执为准。

## 聊天体验

- 表情按对白呈现时机更新，切换加入快速淡出淡入，减少直接换图的生硬感。
- 提前准备角色舞台图片，复用已加载资源，减少切换角色后首次进入面对面的等待；网络和图片解码仍会影响实际速度。
- 文字聊天放大角色与分析员头像，调整对话行、内容宽度和间距，兼顾桌面与手机布局。
- 「接着昨天聊」成为设置中的跨日偏好，默认从今天开始。切换角色无需反复确认，已有本地历史仍可回看。

## 个人订阅与模型选择

- 模型设置提供「Codex 订阅」和原有 API Key 流程。内嵌中文教程说明 Codex 0.153.4 或更新版本、Node.js 22+、本机登录、下载个人连接器和配对步骤。
- 每位使用者登录自己的 ChatGPT 订阅账号并保持个人连接器运行。无需向网站提供 Cookie、`auth.json` 或登录凭据；配对码通过连接器交互输入，不进入 URL 或命令参数历史。
- 连接成功后显示账号实际支持的模型与推理强度。默认优先 Luna Max（`gpt-5.6-luna / max`）；账号不支持时要求明确选择，不静默替换模型。
- 选择在点击「使用所选模型」后生效。状态轮询保留未保存的选择；账号权限改变导致组合不可用时要求重新选择。模型与强度随当前标签页会话保存，旧版 Luna Max 连接器和请求快照保持兼容。
- 聊天与到场反应使用保存的模型和强度。更换配置后的显式重试创建新请求；结果未知时保留原请求编号，不自动重复发送。
- 订阅连接时暂停自动后台摘要，避免与下一条消息争用连接；切回 API 后沿用原摘要偏好。停止连接器或在设置中断开即可停止连接。
- 每人使用自己订阅计划的额度和限流规则。较高强度可能等待更久；额度消耗以订阅计划为准。模型可用范围以当前账号实测目录为准。

详细操作见 [个人订阅连接教程](codex-subscription-connector.md)。服务端未启用订阅连接时，模型设置仍提供教程并说明当前不可配对。

## 兼容性与独立版本

网页/API 与当前前端身份升级为 `1.0.0`。`/public/v1`、`public-state-2`、IndexedDB v4、浏览器存储标识及既有 API Key 流程保持兼容。个人连接器协议 v2 增加模型目录与推理强度，同时兼容 v1 的 Luna Max 行为。

Windows 本地预览仍独立使用 `0.5.0`；内部 Python 包与共享设计资源保持其既有版本。数据、头像、贴纸和舞台资源继续按各自清单发布。S1 兼容前端 `compat-096-r1`、0.9.6 历史基线和此前发布记录保留，本次不升级这些独立版本或数据库格式。

## 验证范围

浏览器回归覆盖默认与主动模型选择、强度选项约束、未保存选择、账号目录变化、重载恢复、聊天和到场请求、旧快照原样重放，以及订阅与 API 的摘要行为。订阅保存测试等待设置弹窗实际关闭后才输入消息，并捕获实际聊天请求；受控延迟响应验证异步保存期间的状态，避免把自动化输入时序误判为聊天故障。

版本合同检查核对当前前端身份、应用发布清单、静态入口版本标识和公告结构。正式发布仍使用既有 CI、签名产物、候选验收与上线后验证流程。
