# 小吉终端 0.10.0-rc.1 候选说明

本候选交付全面优化的第一批基础改造。正式晋级取决于绑定具体提交和产物摘要的验收回执；合并代码、签发证明和准备候选均不等于已切换公网流量。

当前发布选择为 **S1 兼容旧界面**：保留原外观，先部署存储及请求兼容层，并保留其完整镜像作为后续回退目标。下列“小吉终端”名称、图标与布局属于 **S2 新界面**，通过后续正常 main 提交、完整验证和人工晋级启用。镜像只包含所选界面，不能用服务器环境变量跳过此流程。`2b68f60` 新界面的技术候选已通过签名和隔离 stage，但未获准切流。

## 用户可见变化

- 网页和 Windows 预览壳使用“小吉终端”名称及新图标。图标由用户提供的游戏截图经 AI 修复得到，来源说明随资源保留。
- 摘要有期限并支持取消；存储被禁用时提供内存回退；历史清理、同时间戳分页、多标签页草稿和导入失败恢复得到修复。
- 模型配置的取消与迟到响应隔离，移动端抽屉、键盘焦点、长历史渲染和空闲更新提示得到改善。
- 全角色舞台已具备资源校验和回退接口，完整素材通过审核前保持关闭；本候选不启用公网 TTS。

## 服务和维护变化

- 真实模型调用共用预算，请求增加所有权、租约、有界数据库适配、排空及“结果未知”恢复路径。
- 数据激活不删除历史版本；复用向量和图谱时核验实际内容；重复构建保留人工审核决定和来源。
- CI 覆盖删除与重命名、真实 PostgreSQL 升级兼容、浏览器、类型检查及 Windows 预览；只有成功门禁才能签发绑定提交和产物的发布证明。
- 候选执行前验证证明；容量不足、共享依赖配置漂移、过期验收回执均拒绝发布。清理、备份、监控与应用发布分开维护。
- 基线使用永久恢复标签保护；数据库恢复默认拒绝原地覆盖，提供隔离组件恢复演练和按实际在服摘要执行的扫描工具。

## 兼容窗口与独立版本

公网 API 仍使用 `/public/v1` 和现有 SSE 字段；浏览器保持 IndexedDB v4 与 `public-state-2`。支持旧界面回切的目标为从 `App/compat` 可验证构建的 S1 完整产物，包括到场确认期间保留新草稿的修复。未打补丁的原始基线仍保留，但其既有启动草稿覆盖问题不被视为已修复；客户端须刷新到 S1 才进入支持的兼容窗口。

数据库新增迁移 `20260907_0005`，正常应用回滚不降级数据库。组件版本分别保留：网页/API `0.10.0-rc.1`、Windows 本地预览 `0.5.0`、数据与媒体版本由发布清单指定。现有浏览器存储标识、桌面应用标识与用户数据目录不因更名而改变。

## 尚未完成的总计划验收

完整空主机恢复与 RTO、真实模型质量及并发容量测量、剩余大型模块拆分、全角色素材制作和人工审核、全角色 TTS 待审核交付仍独立推进。审核 JSONL 文件现有跨进程保护并不提供多文件断电事务性。外部告警接收目标尚待配置；本地日志告警不等于已通知维护人。

生产执行记录与各项测试的实际范围见 [实施台账](overhaul_progress.md) 和 [恢复手册](../ops/RECOVERY.md)。
