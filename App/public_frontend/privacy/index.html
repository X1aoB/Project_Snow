0.8.1 使用说明

隐私、模型调用与素材来源

这里集中说明沉浸式体验会处理哪些数据，以及当前私有候选所使用的角色头像和表情来源。

API Key

Key 会短暂经过 Project Snow 服务器内存，用于向你选择的官方模型服务发起请求。Key 不写入数据库、磁盘、反馈、IndexedDB 或应用日志；浏览器只在当前标签页保存两小时加密凭证。

本地历史

完整聊天记录和自动摘要以明文保存在当前浏览器 IndexedDB，不会跨设备同步。共享电脑使用后可在设置中删除单个角色记录或清空全部记录。

额外模型调用

进入面对面场景时有 50% 概率触发一次主动到场反应。每新增 12 个成功对话轮次，默认会在后台调用当前模型更新本地连续性摘要；可在设置中关闭。

反馈与 QQ

反馈会附带当前一问一答、结构化动作/对白和不含密钥的阶段诊断。可选 QQ 在数据库中加密保存，并会临时解密后发送到 admin@xiaob.dev 的通知邮件；邮件和数据库记录均在 30 天后清理。原始 IP 不入库。

角色头像来源与许可

头像作为独立媒体包部署，不进入 GPL 应用镜像或 Git 历史。当前私有候选依据用户批准启用；移除 Cloudflare Access 前仍需重新进行公开发布与许可审查。
