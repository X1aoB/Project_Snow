本地设置

        

        

          选择模型厂商
内置厂商只需填写 API Key，客户端会从官方接口读取当前账户可用的模型。Key 只会提交给本地后端并写入 Windows 凭据库，不会保存在聊天数据库中。

          

            

              
              
              
              
              
              
            

            
            
            
            
            
            
            

            
尚未读取当前厂商的模型。

            

              默认模型
沉浸式不在聊天页展示模型信息；助手可在单次任务中覆盖。

              
              
              
              
            

            
改用 Windows PowerShell 环境变量配置
环境变量适合指定一个默认聊天厂商；需要同时保存多个厂商时，请使用上面的厂商按钮和 Windows 凭据库。
在当前 PowerShell 会话设置后，必须在同一个窗口重启 API。长期写入用户环境变量后，需要新开 PowerShell，再重启 API。

          

        

        
会话与存储
只清理本机聊天，不会修改角色资料、反馈或知识图谱。

        
关于本测试版
