# 可选统计适配

`App/public_frontend/statistics/config.mjs` 默认 enabled=false。开启后仍需用户主动允许；仅允许公开角色和页面路径，外域 endpoint 需精确加入 CSP connect-src。

正式配置可由产品进程环境 `PUBLIC_STATISTICS_ENABLED=true` 单独开启；只有完全一致的小写 `true` 生效，缺失或其他值均关闭。`GET /statistics/config.mjs` 仅替换已验收不可变模块的 `enabled` 布尔值，端点、页面和角色名单保持构建包内容。源码始终默认关闭，不需要挂载统计目录，也不会在业务启动、健康检查时读取统计文件或连接统计服务。模块缺失或模板不符时只返回关闭配置，其他业务正常运行。

环境修改后需要按产品发布流程重建指定颜色容器，并重新生成与该环境值、模块响应 SHA256 对应的候选验收记录；原先验收不自动覆盖开启配置。配置响应 no-store，新页面/刷新才读取新配置，已打开页面没有后台配置轮询。全局紧急停收可将独立 collector 切 off；要停止浏览器继续初始化与发送，应将本产品环境改为 false 并重建，用户刷新后生效。用户自己的撤销、同意过期或隐私信号则会在当前页面立即停止适配器并取消在途请求。

单个模块入口注册可删除的适配器；聊天提交点只通过可选回调通知 request_id，默认关闭时回调不存在。不修改请求正文、API、签名状态、浏览器业务存储或数据库。页面队列有界、超时及重试有限，异常与聊天隔离。

启动脚本采用外部 `statistics/start.mjs`，兼容现有禁止内联脚本的 CSP。Caddy 对 `statistics/*` 设置 no-store，避免采集开关被浏览器缓存。合成浏览器验收覆盖默认关闭，以及在生产 CSP 下采集返回 503、连接失败和超时三种情况；聊天使用本地假后端，不产生模型费用。

服务质量来自外部已有脱敏完成日志；日志转发器由 Snow_Statistics 单独部署，不作为聊天服务依赖。访问统计与请求成功指标分别处理，客户端不能申报可信完成。

首次访问告知不阻断聊天。访问选择保存30天；拒绝只保存无标识的否定偏好，同意才初始化独立匿名/会话标识；跨标签撤销立即停止，过期在每次 track/flush 检查。访问选择不控制单独披露的服务质量完成日志，后者只覆盖已记录的生成完成，不能称为全部HTTP请求成功率。入口归因在两个来源各自同意后使用一次跳转标记，目标站未同意时立即移除标记，之后同意不追溯补录。

所有副本随本仓库独立构建、测试、发布，不需要 Snow_Statistics checkout。推广仍遵守 AGENTS.md 的候选验收和手动生产发布流程。

移除：回退 index.html 的统计模块入口、app.js 的可选回调，删除 statistics 目录及相应隐私说明。原有功能兼容不变。
